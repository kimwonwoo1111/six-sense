## 1. 프로젝트 개요

- **목적**: 사거리 교차로의 교통 신호체계를 교통량 기반으로 효율적으로 운영한다.
- **핵심 아이디어**: 완전 고정식 신호가 아니라, 실시간 교통량을 반영해 각 신호에 부여되는 시간을 유동적으로 조절하는 **적응형 신호 제어(Adaptive Signal Control)**.
- **역할 분담**
  - **AI 비전 모델**: 일정 시간 동안 **차량 수**와 **보행자 수**를 카운트하여 알고리즘으로 전달.
  - **알고리즘(본 담당)**: 전달받은 수량을 기반으로 **기준 신호 시간을 유동적으로 조절**.

## 2. 대상 및 범위

- 대상: **사거리(4방향) 교차로**.
- AI 비전 1차 목표: 정해진 시간 동안 방향별 **차량 수 / 보행자 수** 카운트.

## 3. 현시(Phase) 구조

사거리를 기준으로 **총 5개 현시(케이스)**로 구성한다.

| 번호 | 현시(Phase) | 내용 |
|------|-------------|------|
| 1 | 차량 현시 A | 1번 방향 **직진 + 좌회전** 동시 |
| 2 | 차량 현시 B | 2번 방향 **직진 + 좌회전** 동시 |
| 3 | 차량 현시 C | 3번 방향 **직진 + 좌회전** 동시 |
| 4 | 차량 현시 D | 4번 방향 **직진 + 좌회전** 동시 |
| 5 | 보행자 현시 | 사거리 **모든 보행자 동시 횡단** |

- 각 방향은 직진과 좌회전을 함께 처리하므로 상충(충돌) 없음.
- 한 **사이클(cycle)** = 현시 1 → 2 → 3 → 4 → 5 순환 1회.

## 4. 동작 방식 (롤링 윈도우)

- **5사이클**을 하나의 **블록(block)** 단위로 묶는다.
- 한 블록(5사이클) 동안 다음 두 가지를 **동시에** 수행한다.

  1. **직전 블록**에서 수집한 데이터로 계산한 **배분 시간을 적용**.
  2. 그동안 **새 데이터(차량/보행자 수)를 수집** → 다음 블록에서 사용.
- 블록 종료 시: 방금 수집한 데이터로 다음 5사이클의 배분 시간을 계산 → 적용 + 다시 수집 → **반복**.
- 결과적으로 신호 시간은 **5사이클마다 1회 갱신**되며, 항상 **직전 5사이클의 교통량**을 반영한다.
- **최초 블록**: 참고할 이전 데이터가 없으므로 **기준(디폴트) 시간**으로 동작한다.

## 5. 신호 시간 배분 규칙

- 각 현시에는 **기준(디폴트) 시간**이 정해져 있고, 알고리즘이 교통량에 따라 이를 **증가/감소**시킨다.
- 차량/보행자 수가 많은 현시 → 시간 증가, 적은 현시 → 시간 감소.

## 6. 성능 평가 (기존 신호 체계 대비 비교)

본 알고리즘의 효과를 입증하기 위해, **기존 고정식(고정 시간) 신호 체계**를 기준선(baseline)으로 두고
**동일한 교통량 데이터**를 두 방식에 각각 적용하여 성능을 비교한다.

### 비교 방식
- **Baseline**: 현시별 시간이 고정된 기존 신호 체계.
- **제안 방식**: 교통량 기반 적응형 배분(본 알고리즘).
- 동일한 입력(차량/보행자 수 시계열)으로 두 방식을 시뮬레이션 → 지표 비교 → **개선율(%)** 산출.

### 평가 지표 (후보)
- **평균 대기시간**: 차량·보행자 1대(명)당 평균 대기 시간.
- **총 지연시간**: 전체 대기시간 합계.
- **평균 대기열 길이**: 현시별 남은 대기 차량 수.
- **처리량(Throughput)**: 단위 시간당 통과한 차량·보행자 수.
- **정지 횟수**: 신호로 인한 정지 발생 횟수.
- **녹색시간 낭비율**: 통행 수요가 없는데도 녹색 신호가 켜져 있던 시간 비율.
